# Pygame-Snake-Game

This is a basic snake game I created based on the pygame python library. There are a couple of a food colors and size. When the snake eats any of the food/non-snake game element. If the snake eat any food that is golden, its gains temporary invincibility. Typically, if the snake hits the walls or itself, the same dies, but in invincible mode, the snake cannot die. The players current score and current high score and displayed at the top of the game board. Once a player dies, if they hit a center key, they can either restart the game or end it.
